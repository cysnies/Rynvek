# RYN-1：显式Forager基础代谢与能量耗尽自然死亡契约

## 本批决定和原设计边界

原设计D156与项目v1.0 §1.1要求独立能量约束生存、无人工适应度、能量耗尽死亡并分解；冻结采集和发放成本继续复用。六角色通用出生/补能和基础代谢数值并未冻结。本批依据用户明确允许自主设计可配置实验参数的授权，不再因缺数值停在只做账，但也不把新数值冒充原规范。

**不增加第三个生态版本**：在既有 `forager_budget_v2` 中增加可选 `forager_survival` 世界契约，沿真实 `POST /api/v1/worlds` 入口创建。缺省/省略/null均为None，旧V1/V2快照和RTS平衡不自动升级。参数与激活策略必须显式提供：

```json
{
  "title": "显式Forager代谢实验",
  "template": "arena_pve",
  "ecology": "forager_budget_v2",
  "forager_survival": {
    "activation": "after_first_uptake",
    "basal_cost_micro_per_tick": 1000,
    "reserve_ticks": 4
  }
}
```

上例1000 micro/Tick与4 Tick是可调整实验示例，不是冻结默认平衡。无契约时不收费；契约成本须大于0；预留乘法超出精确u64表示范围、缺必填参数、未知字段/激活策略、非V2或排位均拒绝。服务API也执行相同验证，不能只在Rust测试构造器里可用。

## 权威生命周期和守恒

1. 仅玩家Forager进入该契约；其他角色/野生单位无定义供能时不被强制饿死。没有凭空增加出生能量。首次**真实**摄食后激活，由已有单调 `received_q > 0` 永久推导；初次供能前仍是未激活阶段，不声称自主出生/基础吸收完成。耗尽时不能重置激活获得第二次宽限。
2. 沿原阶段执行：已付费的候选脑→真实移动/Harvest→基础代谢→原池预算保留/资源余量转出。基础代谢仅将现有池内可支付量转为热；不足时消耗实际剩余量，不负能、不记伪债务、不对不存在的能量收费。余额在代谢稳定边界（包括余量转出后）归零即自然死亡，精确付清后余额为0也死亡。
3. 自然死亡复用提取出的唯一 `retire_dead_unit` 路径；同一遗骸、私有账本、实体删除和死亡事件在代谢边界完成，之后不能攻击/治疗/采集，重新出现营养也不复活旧ID。不是额外玩具仿真或只修改HP展示。
4. 原池额外保留 `basal_cost_micro_per_tick × reserve_ticks` 的基础代谢预算，再加既有脉冲上界；只把其上完整毫余量转原阵营Biomass。预留不是额外能量或额外收费；相加上界仅饱和至能量池表示范围。
5. 能量耗尽自然死亡时实际剩余池为0，不能从购买造价制造营养；所以该类遗骸归还0，已消耗部分是热。仍有剩余池的HP死亡继续按真实余量75%/90%回收，满场/亚场量子保留遗骸原账，不截断或凭空补齐。
6. 新契约进入原config_root，原ECOL/NEUR与entity_root、检查点和TickRecord/WAL继续复用；不新增可重置的伪生命标志。原ArenaRuntime候选事务失败时，费用、死亡、事件和资源转移一起回滚。

## 红绿与兼容证据

- 首次真实行为红测在JSON参数被旧实现忽略时，实际热耗0而应为4000四分之一micro，正确失败；修复必须真的计费，不能只接字段。
- 加强配置根断言后另有真实红测：修改基础费时config_root竟不变。查实已交付V1/V2都只追加固定legacy标签energy_exchange_v1，并未完整绑定版本身份；上一批“新版本已明确不同根”表述过度。本批新显式契约以独立域加实际生态模式与全部参数绑定，改费/预留必改根；保留旧V1/V2根不暗改历史。旧纯模式身份绑定仍是需显式格式迁移的已知缺口，不能被本批新契约修复掩盖。
- 受控两个交换Tick：真实场1个量子15625，基础费4000、资源转出8000、存量3625；下一Tick无补给，3625全转热后真实死亡。总量严格为热7625+资源8000，无负池、无造价营养；重新供食不能复活。
- 测试覆盖未首次供能不凭空激活/注资、精确归零与欠额、零/极值/溢出参数、75/90%真实余量回收、快照横跨死亡、已执行代谢的失败事务回滚后重试不多扣。
- 合法重封装的CONF改价/移除契约仍被规范根拒绝；另有真实红测发现，已激活零能但尚未退役的活体原可存入检查点。本批补稳定状态验证拒绝此状态，避免恢复后摄食复活；不删除或减弱断言。
- 零预留导出耗尽也有实际红测：32格量子真实摄食得到500000q，基础热耗4000q、资源导出496000q，旧实现未退役零能活体。保留零预留的合法可配置性和所有断言，修复真实同Tick退役，并重验检查点恢复。首轮旧候选HEAD门禁因此主动停止本代理自己的进程，最终HEAD重新完整执行原门禁；未取消远端或其他任务。
- 修改前HEAD 5e09a06的真实V2快照及后续12根冻结于 `tests/arena/forager-budget-v2.json`；原V1和无生态两个夹具不删不改，三个已交付语义都验证无隐藏升级。
- 真实TCP/租约/Harvest/Actor181Tick中，显式高于单Tick摄食量的实验费率用于确认首次进食后的真实代谢死亡；逐段从提交检查点/WAL恢复比较根，不能把只保存参数说成自然死亡已接入。高费率仅测试输入，不是生产默认。
