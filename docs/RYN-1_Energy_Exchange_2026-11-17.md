# RYN-1：个体有来源能量与场交换的首个权威切片

## 依据与范围

- 原设计 D156 要求神经资源参与生命经济；原始封闭环境守恒决策要求只有明确来源/支出才能改变能量。
- 项目文档 v1.0 §1.1 要求独立能量、局部化学交换、能量决定生死繁殖，明确禁止人为适应度；§5.2.1 明定 Forager 营养到 Biomass 为 1:1，死亡剩余能量回收 75%；§5.3.2 的 Forager 采集率及 §5.4 的 800/480 micro-Energy 脉冲成本、90% 超导回收率是本批实际使用的规则。
- 开发规范 v1.0 的 MetabolismAndLifecycle 阶段、INV-03、冻结神经与场求解核仍然保留。
- 未在可核实原文中找到出生内部能量数额、非脉冲基础成本、普遍吸收/分泌系数或“能量场恢复 +25%”的基础恢复率。**不凭空补数值，不将 ERRATA 的护盾再生映射当作用户批准的内部能量恢复。**

这不是自然选择生态闭环完成：本批只结算**有真实营养来源的个体池、实际脉冲支出、原资源账本转移与既有战斗死亡的真实残余归还**。不凭躯体造价生成营养、不初始化虚构出生禀赋，不强行让尚无供能来源的单位全部“饿死”。

## 真实路径与精度

1. `UnitBrain` 复用 `NeuralPopulationRuntime` 的 `PopulationBrainSlot`，仍保留原四子步、Q8.8 模型、调质与均值读出；逐子步统计真实脉冲环最低位，不以动作幅值或 max(1) 发明成本。
2. 共享 `rynvek-neural::metabolism::EnergyAccount` 用四分之一 micro 为内部整数单位。1 个场 Q8.8 原始量为 15625，1 milli 为 4000，0.80/0.48 milli 分别为 3200/1920，二进制场与毫资源转移零漂移。
3. Arena 原采集门控、Forager 速率、实体排序和真实 FieldGrid 不变：先取得实际场量子再扣场；当前 Tick 实际发放扣费后，只向原阵营账本转出可容纳的完整毫单位。亚毫及满仓余量留在原个体池。
4. 收入 = 存量 + 已支付代谢热耗 + 资源转出 + 已归还营养。未获供能的计算成本单独记录 `unfunded_q`，**不是能量、负池、未来债务或适应度**，也不能拿它声称已经实施了计算预算强制停机/饥饿淘汰。
5. 既有 HP 战斗死亡从真实剩余池按 75%/90% 归还，其他进入热耗。满营养格与亚 Q8.8 余量保存在遗骸账本，后续有容量才归还整量子，不截断消失。死亡前已非存活个体不得再次采集/转出能量。
6. 共享群体运行时也不再沿用无规范依据的 output-activity/16 神经能耗。群体根显式升至 V2；该根不是旧 Arena 根。Rust 内部 `UnitBrain` 改为包装共享槽位，`PopulationMember` 的整数毫字段改为精确 `energy` 账本，尚未发布的内部调用点/测试同步迁移，不声称外部 Rust 源码零改动兼容。

## 版本、快照与服务

- 仅**显式选择** `ecology: "energy_exchange_v1"` 的新 PvE 世界启用；真实 `POST /api/v1/worlds` 创建、认证席位、Actor、提交存储和 WAL 恢复使用相同权威路径。
- 默认旧配置不增加 JSON 字段，不自动迁移旧快照/旧比赛，不影响排位。未认证规则在 PvP 配置反序列化及创建接口均拒绝；它不是新产品、玩具模拟或绕过排位的入口。
- 新 `ECOL` 私有块按实体序号保存活体池、待结算真实发放及遗骸，进入 entity_root；版本进入 config_root。`NEUR` 仍只保存神经动态，不能被误称为保存了能量。
- 恢复要求版本/私有块一致、活体集合精确对应、遗骸无重复、位置合法、逐账户守恒。新版本缺块/伪造池即使重建合法通用容器校验也拒绝，不回填虚构默认池。
- `tests/arena/energy-legacy.json` 是修改前 c4da2da 生成的真实旧快照及后续 12 个逐 Tick 根；固定读取验证旧语义，而不是两份新实现互证。
